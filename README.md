## Kitkat Quest

A small platformer created to introduce myself to Godot and learn the basics of 2D game development and game functionality!
This project is mainly a learning project where I experimented with Godot's basic features, including player movement, collisions, NPC behavior, collectibles, and win conditions.

## Current Features
- my pets/friends as sprites (placeholder versions for now)
- an npc that roams and talks + has collision
- fish to collect!!
- platforming to reach the win condition (my dog)
